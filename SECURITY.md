# Security Policy

## Supported version

Security fixes are applied to the latest published release and the default branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not disclose a suspected vulnerability in a public issue.

Include:

- The affected skill version or commit.
- The unsafe behavior and the conditions that trigger it.
- A minimal reproduction that does not contain credentials or private project data.
- The potential impact and any suggested mitigation.

Expect an initial acknowledgement within seven days. A fix timeline depends on severity and reproducibility. No bounty program is currently offered.

## Scope

Relevant reports include instructions that could expose secrets, modify production endpoints unexpectedly, execute outside the intended repository, or weaken the local-versus-production safety boundary.
